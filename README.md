# Предсказание фонем с помощью машинного обучения

Решение для классификации звука фонемы "г" по спектральным данным. Проект разработан для соревнования на Kagge в рамках курса ВШЭ. Используется LDA с продвинутой предобработкой.

## 1. Задача

По 256 спектральным признакам речевого сигнала предсказать, является ли фонема звуком "г" или нет. Основные сложности — высокая размерность данных и вариативность признаков у разных дикторов.

## 2. Методология

### Предобработка

1.  **Нормализация по диктору:** Z-нормализация признаков для каждого диктора отдельно, чтобы убрать индивидуальные особенности голоса.
2.  **Стандартизация:** Применение `StandardScaler` ко всем данным.
3.  **PCA:** Снижение размерности со 256 до 50 компонент для борьбы с переобучением и ускорения вычислений.

### Модель

**LDA с Shrinkage-регуляризацией.**
*   **Почему LDA:** Теоретически обоснован для таких задач и эффективен.
*   **Зачем Shrinkage:** Стабилизирует оценку ковариационной матрицы и снижает переобучение. Параметр регуляризации подбирается по кросс-валидации.

## 3. Реализация

*   **Стек:** Python, `scikit-learn`, `pandas`, `numpy`.
*   **Процесс:** Нормализация → Стандартизация → PCA → LDA.

## 4. Результаты

Модель эффективно снижает размерность, нивелирует различия между дикторами и укладывается в лимит по времени (60 сек.), при этом имея точность 0.9386.

## 5. Ключевые идеи

1.  Нормализация по диктору критически важна для обобщающей способности.
2.  PCA эффективно сжимает данные без потери качества.
3.  Регуляризация необходима для стабильности LDA.
4.  Порядок предобработки (нормализация → стандартизация → PCA) имеет значение.
